# Regras do prosperediario-site

Leia primeiro: `CONTEXTO.md`.

1. Siga o padrão DROPZ (skill `padrao-apps-dropz`): ramo novo para toda mudança, prévia, PNG para o Lipe aprovar, só então `main`.
2. Nunca mudar `privacidade` ou `termos` sem o Lipe saber: eles foram enviados para a Meta e para o Google.
3. Nada de Google Fonts, CDN ou script de fora sem rever a CSP do `vercel.json`.
4. Texto no tom do Prospere: sem promessa de ganho, sem "fique rico", sem travessão, sem depoimento ou número inventado.
5. O link de compra é sempre o checkout da Kiwify: https://pay.kiwify.com.br/3ICab1J
